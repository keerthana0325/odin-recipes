# odin-recipes


A basic recipe website built as part of The Odin Project Foundations course.

## Features

- Homepage with links to recipes
- three recipe pages
- Built using HTML

## Recipes

- Chocolate Lava Mug Cake
- Garlic Bread
- Oreo Milk Shake

## Skills Demonstrated

- HTML boilerplate
- Links and navigation
- Lists
- Images
- Basic website structure
